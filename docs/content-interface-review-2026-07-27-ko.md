**제안:** `hub/app/basic/` 렌더러에서 이 블록을 숨기거나 개발자 콘솔 전용으로 옮기기.

**어디:** `hub/app/hangul/` — 레슨을 펼치면 제목 바로 아래 "종류" 행에 내부 `kind`/`slug` 값이 그대로 나옵니다.

**제안:** "종류" 행 자체를 제거하거나, 최소한 사람이 읽는 라벨로 교체.

### 1-3. Hangul 퀴즈 선택지가 영어 고정 — KO/ZH 모드에서도 영어로 노출

**어디:** `hub/app/data/hangul/track-manifest.json`의 `check` 타입 모듈. `prompt`·`tip`은 `{en,ko,zh}`로 잘 다국어 처리돼 있는데, **`choices` 배열만 영어 문자열 하나로 고정**되어 있습니다. 예:

```json
"prompt": { "ko": "받침 ㅇ 소리는?", ... },
"choices": ["silent", "h", "ng", "same as initial ㅇ"]
```
```json
"prompt": { "ko": "ㄴㅁㄹ은 어느 그룹?", ... },
"choices": ["Stops ㄱㄷㅂ", "Soft / nasal-ish", "Aspirated ㅋㅌㅍㅊ", "Vowels"]
```

한국어/중국어 모드로 앱을 봐도 이 선택지들은 그대로 영어로 뜹니다. 36개 `check` 문항 중 **최소 15개 이상**이 이 패턴(grep 확인). 실제 한글 낱자/단어가 선택지인 문항(예: `["ㄱ","ㅏ","가 전체","ㅇ"]`)은 문제없음 — 영어 문법 용어(Stops/Aspirated/silent 등)가 선택지인 문항만 해당.

**비교 확인:** TOPIK I/II·기초·게임 데이터의 `choices`는 전부 실제 한국어 어휘/문항이라 다국어 이슈 없음(정상). 이 버그는 Hangul 트랙 고유.

**제안:** `choices`를 다른 필드처럼 `[{en,ko,zh}, ...]` 구조로 바꾸고 렌더러 수정.

### 1-4. Basics 요약 카운터가 실제 콘텐츠와 모순

**어디:** `hub/app/basic/` 최상단 — `jabi-basic-v0 · v3 · pilot · 6 units (0 filled)`

바로 아래 리스트에는 6개 유닛 전부 "8 Q"로 표시되어 실제로는 다 채워져 있는데, 요약 줄은 "0 filled"로 나옵니다. 카운터 로직이 `status` 필드나 다른 조건을 잘못 보고 있는 것으로 추정.

### 1-5. (경미) 레슨 안에서 같은 스텝 배지가 카드마다 반복

Hangul/Basics 레슨 상세에서 같은 스텝(예: "2 · 배우기") 안에 카드가 여러 장 있으면 그 배지가 카드마다 다시 나옵니다. 정보 전달엔 문제없지만 시각적으로 산만함 — 스텝이 바뀔 때만 헤더로 한 번 보여주는 편이 깔끔합니다.

## 2. 콘텐츠 — 확인·수정 필요

### 2-1. "음악" 연음 예시 로마자 표기 오타

**어디:** `hub/app/data/hangul/track-manifest.json`, 14과(연음) examples.

```json
{ "ko": "음악", "gloss": { "en": "e-mak link", ... } }
```

표준발음법 연음 규칙(받침 뒤 모음 시작 형태소 결합 시 대표음을 다음 음절 초성으로 이동)에 따르면 「음악」은 받침 ㅁ이 다음 음절로 넘어가 **[으막]**으로 발음됩니다. `en` 게로스의 "e-mak"은 "eu-mak"의 오타로 보입니다(ㅡ를 "e"로 잘못 표기). 같은 레슨의 다른 예시(한국어≈han-gu-geo, 있어요≈i-sseo-yo, 꽃이≈kko-chi, 옷이≈o-si)는 모두 정확합니다.

**제안:** `"e-mak"` → `"eu-mak"`.

## 5. 확인되지 않은 것 (false alarm 정정)

캐릭터 선택 화면(TOPIK I 온보딩 4단계)에서 처음엔 ㄴ~ㅎ 카드가 전부 빈 화면으로 보여 "이미지 깨짐"으로 의심했으나, DOM/네트워크 레벨로 재확인한 결과 **giyeok·nieun만 실제 `<img>` 요소가 있고 나머지 11자는 원래부터 텍스트 라벨만 있는 상태**(아직 아트 없음 — 정상, N7b Canva 파이프라인 진행 중)였습니다. giyeok·nieun 이미지는 정상 로드됨(`naturalWidth` 확인). 버그 아님 — 오탐 정정.

## 9. (신규) R1 배포 후 재검증 결과 — 전부 정상 반영

로컬 서버로 R1 이후 최신 working tree를 다시 띄워 4개 항목 전부 실제로 확인:

- **1-1 Basics 디버그 블록** → 사라짐. "8 practice questions" + "Practice dialogue →" 버튼만 남음.
- **1-2 Hangul "종류" 필드** → 사라짐.
- **1-3 Hangul 퀴즈 choices 다국어화** → KO 모드에서 "파열음 ㄱㄷㅂ" / "부드러운·비음 쪽" / "격음 ㅋㅌㅍㅊ" / "모음"으로 정상 출력(이전엔 Stops/Soft-nasal-ish/Aspirated/Vowels 영어 고정).
- **1-4 Basics 카운터** → "6 units (6 filled)"로 정상.

추가로 D1(디자인 리프레시)도 실제 반영 확인 — 홈 화면 남색 캐릭터 배지, 퀴즈 A/B/C/D 원형 뱃지, 탭바 이모지 아이콘 전부 스펙대로 나옴. TOPIK I 리딩 문항 1개를 실제로 풀어 제출까지 확인(정답 처리 정상, 다음 문항으로 이동). Games Speed Quiz 1문항 확인(한↔영 혼합 유형 정상, 콘텐츠 정확).
