## 1. UI가 데이터를 쓰는 방식

- Hanzi Writer + `charDataLoader` → JSON의 `strokes[]`(SVG path) · `medians[]`(채점·애니 중심선).
- 좌표계 **1024×1024**, Y축 **위로 증가**(SVG와 반대). 라이브러리가 `scale(s,-s)`로 화면 SVG에 맞춤. 과거 ㄱ 좌우·상하 버그는 이 축 오해에서 생김.
- **Replay** = `animateCharacter` · **Trace** = `quiz`(3 miss → hint). 재생 속도: **전 자모 동일** `STROKE_ANIM_SPEED = 0.5`, `STROKE_DELAY_MS = 450` (길이 비례 → 체감 균일).
- 상단 로스터 + 레슨 `trace` 모듈이 같은 `renderRoster`를 씀.
- 자모에 `GLYPH_TO_ID` 매핑이 없거나 JSON 키가 없으면 **「준비 중」** (비활성).
- 획순 UI 크롬 글꼴: **Gulim / 굴림** (`Malgun Gothic` 폴백) — **헤더·로스터 라벨만**.
- **중요:** 연습 캔버스는 JSON `strokes[]`만 사용. **CSS 굴림 고스트 오버레이는 제거** (폰트≠path 어긋남 — Paul 스크린샷).

## 1b. 방향 수정 노트 (2026-07-26 저녁 · Paul 스크린샷)

- **증상:** Trace 패널 큰 글자가 헤더 참고 ㅂ과 반대로 보임(위가로·가운데가로 · 아래 열림 = 뒤집힌 ㅂ).
- **원인:** 전역 CSS/`transform` 뒤집힘이 **아님**. Hanzi Writer Y-up에서 **ㅂ(`bieup`) 제3획(아랫가로)을 Y≈750(위)에 넣어** 모양이 뒤집힘. ㄱㄴㄷ 등은 이미 Y-up에 맞게 제작됨.
- **수정:** `bieup`·`ssangbieup` 아랫가로를 Y≈150(아래)로 이동 + median 동기화. 나머지 자음은 재검 후 유지.
- **모음:** 앱 로스터에 없음. JSON `ji`는 세로 1획(ㅣ 형태) 스텁·**ㅈ로 쓰지 않음**.

## 4. 패스·배지와 맞출 규칙 (이 학습의 결론)

1. **획순 배지** = `trace` 모듈이 있고, 레슨에서 실제로 연습시킬 자모 중 **완전 JSON**(스텁 제외)이 1개 이상일 때만.
2. **ㅈ / ㅉ** = 문해(읽기) 예·그룹에는 가능, Trace 셀·경음 미리보기에는 **넣지 않음**.
3. **기본 자음 미리보기** = 가나다순이 아니라 **`ㄴㅁㄹ · ㄱㄷㅂ · ㅅㅈ`** 묶음 문자열.
4. 레슨 메타에 **`pilot` 문자열을 카드/디테일 배지로 반복 노출하지 않음**.
5. 가르침 본문이 “획순 연습”을 말할 때, 데이터 없는 글자는 **준비 중**이라고 명시.
