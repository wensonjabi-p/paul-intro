## 1. 결론 (채우기 원칙)

1. **경로 뼈대 = TOPIK I·A1 생존 기능 6단원** (인사 → 일상 → 카페 → 쇼핑 → 길찾기 → 식당). Duolingo식은 **UI 스킬 패스(Intro→Teach→Dialogue→Practice→Checkpoint)** 만 빌림.
2. **세종한국어 1 본단원 순서와 1:1 복제하지 않음.** 세종 1은 `자기소개→일상→위치→물건사기1–2→어제…` 12단원+문화. jabi. 6단원은 **초급 초반+생존 과제**로 압축·재배치.
3. **카페(03)를 쇼핑(04) 앞에 둔 이유:** TOPIK I 1급 can-do(자기소개·쇼핑·음식 주문)와 교실 빈도상 **짧은 거래(음료+원)** 가 물건 사기(사이즈·색깔)보다 먼저 성공 경험을 줌. 세종 1 TOC에 “카페” 단원명은 없어도, 표준 주제 **식음료**·1A 음식 단원 역할에 해당.
4. **길찾기(05) = 세종 「위치」+ 거리 안내.** 세종 3과는 사물 위치(`에 있다/없다`) 중심. jabi.는 여행자 생존을 위해 **직진·좌/우회전**을 같은 스킬에 묶음(UQ Level 1 Places · 일반 A1 syllabus와 정합).
5. **문법 = 단원당 1–2개만.** 세종 1과 문법 표(이에요/예요·은/는 / -아요/어요·에 가다 / 이/가·에 있다 …)를 **앵커**로 쓰고, 문장은 전부 원작.
6. **표현·대화 = jabi. 원작.** 인물명·카페 주문·금액은 교실용 가상 장면(민수/민준, 아메리카노 사천 원 등).

## 3. 세종 1 vs jabi. 6단원 — 매핑

| 세종한국어 1 (교실) | jabi. Basic | 채택 이유 |
|---------------------|-------------|-----------|
| 예비편(한글) | **한글 트랙** (#1) | 이미 분리 |
| 1과 자기소개 | **01 인사** | 동일 기능 |
| 2과 일상생활 | **02 일상** | 동일 기능 |
| 3과 위치 | **05 장소·길** (일부) | 위치+길 압축 |
| 4–5과 물건 사기 | **04 쇼핑** | 1+2과 압축 |
| (식음료·주문 — 1 후반/1A·TOPIK) | **03 카페** · **06 식당** | 생존 거래 2단원 |
| 6–12과(어제·날씨·시간·약속·주말·공부·계획) | **후속 확장** | 이번 6단원 범위 밖 |

**시사점:** jabi.는 세종 **초반 주제 + TOPIK 생존 과제**를 6스킬로 압축한다. 날씨·약속·과거(`았/었`)는 이번 fill에 넣지 않음.

## 4. 교수법 요약 (채우기에 직접 쓰는 규칙)

### 4-1. 단원 내부 UX (유지)
`intro → teach → dialogue → practice(MCQ) → checkpoint` · 대화 원작 · 힌트는 정답 단어 선공개 금지(기존 hint UX).

### 4-2. 문법 앵커 (단원별)

| ID | 핵심 문법 | 핵심 기능 |
|----|-----------|-----------|
| **01** | 이에요/예요 · 은/는(가벼운 주제) | 인사·이름·국적·반가워요 |
| **02** | -아요/어요 · 에(시간) / 에서(동작 장소) · (장소)에 가요 | 지금 뭐 해요 · 루틴 |
| **03** | 주세요 · N잔 · 얼마예요 · 한자어 수+원 | 음료 주문·포장·결제 |
| **04** | 있어요/없어요 · 이거 · 봐도 돼요? · 원 | 재고·사이즈·색·가격 |
| **05** | 어디예요 · 에 있어요 · 직진/돌다 | 위치·길 안내 |
| **06** | 주세요 · 안+형 · 계산해 주세요 | 인원·주문·맵기·계산 |

### 4-3. 어휘 범위
- TOPIK I·초급 고빈도만. 전문·한자 과다 금지.
- 숫자: 카페·쇼핑·식당에서 **원(한자어 수)** 우선. 고유어 수는 “한 잔/두 명” 정도만.
- 카페 음료명(아메리카노 등)은 실제 간판 차용어 — 교실 생존용으로 허용(교재 복제 아님).

### 4-4. 넣지 말 것
- 세종/SNU 교재 원문·듣기 스크립트
- 과거형 본격(`았/었`), 청유·제안 심화, 높임법 체계 전부
- TOPIK 시험 문항 스타일(지문 독해) — 기초는 **대화 완성 MCQ**
