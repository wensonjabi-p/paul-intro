## 1. 결론 (채우기 원칙)

1. **경로 뼈대 = 세종 입문 00–17 교실 순서** (모음→기본자음→격/경→이중모음→받침→겹받침→연음→표현). Duolingo식은 **UI 스킬 패스(Intro→Teach→Practice→Checkpoint)** 만 빌려 온다.
2. **자모 제시 = 가나다순이 아니라 소리·모양 묶음.** 기본 자음은 `ㄴㅁㄹ → ㄱㄷㅂ → ㅅㅈ` (기존 구현 리서치와 세종 교실 그룹 원리 정합).
3. **받침 = 위치 인식 → 7대표음 → 끝소리 줄임 → 연음 → 겹받침.** 비음화·경음화 등 고급 음운 규칙은 이 트랙에서 깊게 다루지 않음.
4. **획순 = 국립국어원「한글 맞춤법」은 자모 수·순서·이름만 규정, 필순(획순) 공식 표준은 없음.** jabi. 획순 데이터는 초등·쓰기 교육에서 통용되는 **가로=왼→오 · 세로=위→아래** 관행을 따르며, UI의 stroke JSON을 유지.
5. **표현 16–17 = jabi. 원작 생존 문장.** 세종 표현 편 “자주 쓰는 표현” **역할만** 맞추고 문구는 새로 씀.

## 4. 교수법 요약 (채우기에 직접 쓰는 규칙)

### 4-1. 음절 구조
- 블록 = **초성(자음) + 중성(모음) + (선택) 종성(받침)**.
- 초성 자리 비면 **ㅇ = 자리만 지킴(무음)**. 종성 ㅇ = **ng** — 같은 글자, **역할이 다름** (00·03·10에서 반복 강조).
- 읽는 방향: 블록 안 **왼→오, 위→아래** (훈민정음 합자 원리 / Duolingo tips와 동일 관찰).

### 4-2. 모음
- 기본 8: `ㅏㅓㅗㅜㅡㅣㅔㅐ` (세종 입문 「기본 모음」).
- 형태 힌트(교육용): **세로형** ㅏㅓㅣ · **가로형** ㅗㅜㅡ · ㅔ/ㅐ는 초급에서 **비슷한 ‘에’** 로 듣고 철자는 나중에 정교화(현대 구어 합류 — Duolingo tips와 일치).
- 이중1: `ㅑㅕㅛㅠ` = 기본에 **y-glide**.
- 이중2: `ㅘㅝㅟㅢ` = 부품 결합(`ㅗ+ㅏ`…). (공개 목차의 double vowels 2에 해당; `ㅚ/ㅙ/ㅞ` 등은 후속 확장 가능·이번 채우기에서는 핵심 4개 유지.)

### 4-3. 자음
- 기본 8: `ㄱㄴㄷㄹㅁㅂㅅㅈ` — **그룹 학습** (ㄴㅁㄹ → ㄱㄷㅂ → ㅅㅈ).
- 격음 `ㅋㅌㅍㅊ` = 같은 자리 + **숨 더**.
- 경음 `ㄲㄸㅃㅆㅉ` = **조임·짧고 단단**. 삼중 드릴 `가·카·까`.
- `ㅇ/ㅎ`는 연습활용1에서 합류(자리 ㅇ · 숨 ㅎ) — 기존 트랙 설계 유지.

### 4-4. 받침 (필수 순서)
1. **위치** 보기 (가 vs 간).
2. **7대표음** `ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ`.
3. **미방출** — 끝에서 모음을 덧붙이지 않기 (`밥` ≠ ba-buh).
4. **끝소리 줄임** — `ㅅ/ㅆ/ㅈ/ㅊ/ㅌ/ㅎ` 등 → **ㄷ 계열** 등.
5. **겹받침** — 철자는 둘, 단독 발음은 대개 하나; 다음이 모음이면 연음.
6. **연음** — 다음 초성이 무음 ㅇ이면 받침이 넘어감.

### 4-5. 획순
- 국어원 맞춤법은 **필순 미규정** → “공식 표준”이라고 쓰지 말 것.
- 교육 관행: 가로 왼→오, 세로 위→아래. 예) ㄱ 2획, ㄴ 2획, ㄷ 2획, ㄹ 3획, ㅁ 3획, ㅂ 4획.
- jabi.는 **기존 stroke JSON 배선 유지**; 레슨은 “따라 쓰기” 과제만 연결.
