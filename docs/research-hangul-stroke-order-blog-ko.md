### 블로그가 특히 강조한 복병

- **ㄷ**: 한 번에 쓰지 말 것 → [긋고, 니은]
- **ㄹ**: [기역, 긋고, 니은]으로 연상 (한꺼번에 내리쓰기 금지)
- **ㅌ**: ㄷ을 쓴 뒤 가운데를 넣는 것이 **아님** → [긋고, 긋고, 니은]
- **ㅂ / ㅁ**: “닫고” 니모닉 + **위→아래** 원칙 → ㅂ의 두 가로획은 **가운데 먼저, 아래 나중**

## Paul 스크린샷에서 확정한 UI 버그

- Replay 중 **검정 HW path**와 뒤 **굴림 CSS 고스트**가 따로 움직임/어긋남 (ㅋ·ㄴ·ㄹ).
- 원인: 폰트 글리프 메트릭 ≠ pedagogical median 박스. 동기화 불가에 가깝다.
- **결정:** 연습 패널에서 floating Gulim overlay **제거**.
  - **Replay:** `hideOutline` — 검정 잉크만 (이중 레이어 착시 없음).
  - **Trace:** `showOutline` — 회색 가이드도 **같은 strokes[]**.

## 속도

- `strokeAnimationSpeed` 전 자모 **동일** (길이 비례 → 체감 속도 균일).
- `delayBetweenStrokes`를 과도하게 길게 두지 않음 (짧은 획이 ‘瞬발’처럼 보이던 착시 완화).
- 목표: **균일 medium / 약 ½** — 자모·획마다 다른 배속 금지.
