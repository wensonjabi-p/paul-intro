## 0. 지금 실제로 어떻게 되어 있는지 (코드 확인함)

- **캐릭터 성장은 TOPIK I 앱에만 있음.** `hub/app/js/app.js`의 `state.profile.partnerId` 필드 하나 — 온보딩 4단계("자음 짝 고르기")에서 한 번 고르면 `topik-coach-v1`(localStorage)에 저장되고, TOPIK I 홈 화면의 남색 배지 캐릭터가 이 값을 계속 씀. **전역 하나, TOPIK I 전용.**
- **한글·기초 트랙은 XP/스킬 진행만 있고 캐릭터 성장이 아예 없음.** `JabiPathProgress`(`jabi.hangul.v1` / `jabi.basic.v1`)가 XP·스킬 완료·체크포인트·크라운은 추적하지만 partner 캐릭터 개념 자체가 없음.

- 즉 Paul이 요청한 "섹터마다 캐릭터"는 리팩터가 아니라 **기능 확장**입니다 — TOPIK I 하나에만 있는 걸 4개 트랙 전부로 넓히는 일.

## 1. 섹터별 캐릭터 — 목표 동작

**섹터 = 학습 트랙 4개**: 한글 읽기·쓰기 / 기초 수업 / TOPIK I / TOPIK II.

- 각 섹터에 처음 들어갈 때(그 섹터의 로컬 상태에 partnerId가 없을 때) 딱 한 번 "자음 짝 고르기" 화면(기존 TOPIK I 온보딩 4단계 컴포넌트 재사용)을 보여준다.
- 고른 캐릭터는 **그 섹터 전용**으로 저장되고, 그 섹터 안에서 XP를 쌓을 때마다 그 캐릭터만 성장한다(스테이지 1→6).
- 다른 섹터에 처음 들어가면 다시 한 번 고르라고 물어본다 — **섹터마다 독립된 선택 + 독립된 성장 상태**.

### 데이터 모델 제안

기존 트랙별 localStorage 키에 `partner` 필드를 얹는다(새 키 만들지 않고 기존 스키마 확장):

```
jabi.hangul.v1   → { ...기존 XP/스킬, partner: { id: "nieun", stage: 3 } }
jabi.basic.v1    → { ...기존,          partner: { id: "giyeok", stage: 1 } }
topik-coach-v1   → 이미 partnerId 있음 → { id, stage } 형태로 통일(아래 참고)
topik2-...       → 아직 진행 상태 저장 키 자체가 약함 — 이 작업과 별개로 먼저 필요할 수 있음(Cursor 확인)
```

`stage` 계산 로직(XP→스테이지 임계값)은 TOPIK I `app.js`에 이미 있는 것(`charArtSrc(partnerId, stageNow)` 등)을 그대로 재사용 — 새로 설계할 필요 없음, 트랙마다 그 로직을 부르기만 하면 됨.

### 열린 질문 (Cursor 구현 시 결정 필요, Paul 확인 권장)

1. **같은 캐릭터를 여러 섹터에서 골라도 되는가?** (예: giyeok을 한글에서도, TOPIK I에서도) — 기본값 제안: **허용**. 섹터별로 독립 성장하니 겹쳐도 자연스러움(오히려 "내가 좋아하는 캐릭터"라는 애착 포인트가 됨).
2. **13파트너 전부 아직 아트 없음**(giyeok·nieun만 진행 중) — 아트 없는 섹터/캐릭터 조합은 지금 "자음 짝 고르기" 화면처럼 텍스트만 있는 카드로 자연 폴백(이미 그렇게 동작 확인함, 새로 만들 것 없음).

## 2. 난이도·언어 — 최초 1회 + 설정에서 변경

- 지금 온보딩 1~4단계(모국어/TOPIK 지역/이전 학습/목표 학습량/하루 학습시간 + 시험 날짜 + 모드 + 파트너)는 **온보딩 완료 후 다시 안 물어보는 게 이미 의도**로 보임(`onboardingDone` 플래그 존재, 코드 확인함) — 그런데 이 값들을 **나중에 개별로 바꾸는 UI가 없음**. 지금 "나" 페이지엔 "모드 변경"·"온보딩 다시하기"(전체 리셋) 버튼만 있음.
- **필요한 것: 설정 페이지 하나** — "나" 탭 안에 섹션으로 추가 제안(새 탭 안 만들어도 됨):
  - 모국어, TOPIK 응시 지역, 목표 학습량, 하루 학습 시간 — 개별 드롭다운으로 즉시 변경(현재 값 프리필).
  - 위 §1의 섹터별 파트너도 여기서 "다시 고르기" 가능하게(섹터마다 버튼).
  - "전체 온보딩 다시하기"는 지금처럼 별도 위험 버튼으로 남겨둠(구분).

## 3. 명예의 전당 (Hall of Fame)

**위치:** TOPIK I 앱의 "나" 페이지, 기존 "예상 준비도" 분석 카드 위나 아래에 새 섹션.
