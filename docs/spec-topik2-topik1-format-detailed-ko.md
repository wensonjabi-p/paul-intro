# TOPIK II를 TOPIK I 형식으로 개선 — 상세 재검토 (2026-07-27, 라이브 재확인)

> Paul 지시로 TOPIK II를 다시 확인하고 TOPIK I 형식으로 개선하는 방법을 상세히 정리. 로컬 서버로 두 트랙을 처음부터 다시 조작해 재검증했고, **기존 [`spec-topik2-unit-list-unify-ko.md`](spec-topik2-unit-list-unify-ko.md)(N12)를 쓴 이후 SpecPartner 기능이 새로 배포되면서 구조적 차이가 하나 더 생긴 것을 발견**해 이 문서로 갱신·확장합니다.

---

## 1. 재확인 결과 — 핵심 구조 차이 (표)

| 구분 | **TOPIK I** (`hub/app/index.html` + `app.js`) | **TOPIK II** (`hub/app/topik2/`) |
|---|---|---|
| **전체 화면 구조** | **탭 3개**(Home / Practice / Me) — 서로 다른 화면, 하단 탭바로 전환 | **탭 없음** — 진입하면 캐릭터 위젯 + 유닛 목록이 **한 페이지에 다 있음** |
| **캐릭터·XP 위젯** | **Home 탭에만** 존재(캐릭터 스테이지, XP바, 스트릭, "오늘의 미션") | **유닛 목록 맨 위**에 존재(SpecPartner로 신규 추가됨) — 목록과 뒤섞여 있음 |
| **문항/유닛 목록** | **Practice 탭** — 섹션별(Reading/Listening) 평평한 목록, 텍스트 링크 | 탭 없는 단일 화면 — 00~13 번호 원형 배지 세로 목록(`.skill-path`) |
| **비기능 항목** | 없음(전부 실제 세트) | "00·Overview"(스캐폴딩)·"13·Full mock(planned, 콘텐츠 없음)"이 01~12 실제 연습 유닛과 **섞여서** 노출 |
| **프로필/분석/설정** | **Me 탭** — 준비도 분석, 강점/약점, 프로필(모드·파트너), 실제 TOPIK 성적 입력(N10) | 없음 — 실제 성적 입력 폼(N10)은 유닛 목록 맨 아래에 그냥 붙어 있음, 파트너 선택은 최초 진입 시 게이트로만 존재(수정 불가) |
| **AI 코칭(N9)** | 해당 없음(TOPIK I엔 AI 코칭 없음) | 유닛 상세를 펼쳤을 때만 등장(리스트 화면엔 없음) |

**결론**: N12(기존 스펙)가 다룬 "목록 섹션 그룹핑 + 비기능 항목 분리"는 여전히 유효하고 필요하지만, 그것만으로는 "TOPIK I 형식"이 되지 않습니다. **더 근본적인 차이는 TOPIK I이 Home/Practice/Me 3개 화면으로 역할이 나뉘어 있는데, TOPIK II는 그 전부가 한 화면에 뭉쳐 있다는 것**입니다. SpecPartner가 캐릭터 위젯을 추가하면서 이 문제가 더 뚜렷해졌습니다(홈 화면 콘텐츠가 리스트 화면 맨 위에 얹힘).

## 2. 결정 필요 — 두 가지 개선 범위

### 옵션 A — 최소안 (기존 N12 스펙 그대로)
목록만 섹션 그룹핑 + 비기능 항목 분리. 캐릭터 위젯·성적 입력 폼 위치는 지금처럼 목록 화면에 그대로 둠. 공수 작음, 하지만 "TOPIK I 형식"이라 부르기엔 부족함(구조 자체는 안 바뀜).

### 옵션 B — 구조 이식안 (권장)
TOPIK II도 TOPIK I처럼 **Home / Practice / Me 3탭 구조**로 재구성:

- **Home 탭**(신설) — 지금 목록 맨 위에 있는 캐릭터·XP·스테이지 위젯을 여기로 이동. TOPIK I Home과 같은 역할(오늘의 진행 상황 요약).
- **Practice 탭**(= 지금의 목록, 옵션 A의 개선 적용) — 00~13을 듣기/읽기/쓰기 섹션으로 그룹핑, "00·Overview"·"13·Full mock"은 별도 "예정" 구역으로 분리하거나 숨김. AI 코칭(N9)은 그대로 유닛 상세 안에서 동작.
- **Me 탭**(신설) — 파트너 변경(지금은 최초 1회 게이트뿐이라 나중에 못 바꿈 → Me 탭에서 바꿀 수 있게), 실제 TOPIK 성적 입력 폼(N10, 지금 목록 맨 아래 있는 것 이동), 향후 N13(온보딩 분리) 작업의 "학습자 페이지"와도 자연스럽게 연결됨.

**권장 이유**: Paul이 "토픽1 형식으로" 요청을 반복하신 것으로 보아, 리스트 스타일만 맞추는 옵션 A보다 **탭 구조 자체를 TOPIK I과 동일하게** 만드는 옵션 B가 실제 의도에 더 부합할 가능성이 높습니다. 또한 옵션 B는 이미 승인된 N13(온보딩·설정 분리) 스펙과도 자연스럽게 맞물립니다 — Me 탭이 있으면 N13이 요구하는 "설정 화면"을 TOPIK II 안에도 쉽게 만들 수 있습니다.

**비용**: 옵션 A보다 공수가 더 큽니다 — 새 탭바 UI, 3개 화면 분리, 기존 단일 페이지 렌더링 로직 재구성이 필요합니다.

## 3. 상세 구현 계획 (옵션 B 기준)

### 3-1. 탭바 신설
`hub/app/topik2/topik2.js`에 TOPIK I의 `setActiveTab()`/`goTab()`(`app.js` 1017~1048행) 패턴을 참고해 3개 뷰 전환 로직 추가. 코드 자체를 공유하진 않음(두 앱이 물리적으로 분리돼 있으므로) — **패턴만 참고해 TOPIK II 내부에 독립적으로 구현**.

### 3-2. Home 탭 — 캐릭터 위젯 이동
현재 `renderList()`(1498행) 맨 위에 렌더링되고 있는 SpecPartner 캐릭터·XP·스테이지 위젯(`partner-sector.js` 관련 로직으로 추정 — 정확한 함수명은 Cursor가 실제 코드에서 확인)을 새 `renderHome()` 함수로 분리.

### 3-3. Practice 탭 — 목록 개선 (기존 N12 내용 그대로 적용)
- 섹션 헤더(듣기/읽기/쓰기)로 00~13 그룹핑.
- "00·Overview"·"13·Full mock(planned)"을 실제 연습 유닛(01~12)과 분리 — 별도 "예정 콘텐츠" 구역 또는 숨김.
- `skill-node` 원형 배지는 유지(트랙 고유 요소, Basics와도 통일된 요소이므로 — 이 부분은 이전 옵션 B(트랙 일관성) 결정 그대로 유지).

### 3-4. Me 탭 — 신설
- 파트너 변경 UI(지금은 최초 게이트로만 선택 가능 → 여기서 다시 바꿀 수 있게).
- 실제 TOPIK 성적 입력 폼(N10, `topik2-official-score-label` 등 기존 요소를 목록 화면에서 이 탭으로 이동).
- (선택, N13과 연계) 학습 설정 항목이 있다면 여기 포함.

### 3-5. 기존 유닛 상세·AI 코칭 로직
`renderDetail()`, `aiCoachPanelShellHtml()` 등 기존 로직(N9)은 **그대로 유지** — Practice 탭 안에서 유닛을 펼쳤을 때 동작하는 방식은 안 바뀜, 탭 구조만 그 바깥을 감쌈.

## 4. 회귀·검증 체크리스트

1. Home/Practice/Me 3탭 전환이 정상 동작하는지.
2. 캐릭터·XP 위젯이 Home 탭에서만 보이고 Practice 탭(목록)엔 더 이상 안 뜨는지.
3. Practice 탭 목록이 섹션 그룹핑되어 있고 비기능 항목(00·13)이 분리돼 있는지.
4. 파트너 변경이 Me 탭에서 실제로 가능한지(최초 게이트 이후에도).
5. 실제 TOPIK 성적 입력 폼이 Me 탭으로 옮겨져도 N10 API 호출이 그대로 정상 동작하는지(회귀 없어야 함).
6. 유닛 상세(N9 AI 코칭 포함)가 Practice 탭 안에서 기존과 동일하게 작동하는지.
7. `git commit`/`push`는 Paul 요청 전까지 보류.
