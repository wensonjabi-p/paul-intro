# 획순 트레이싱 파일럿 (ㅣ·ㅇ·ㄱ)

> `docs/research-stroke-order-ui-ko.md`의 파일럿 실행 결과. `app.js`는 안 건드림(Cursor 소유) — 여기 결과를 Cursor가 통합할 때 참고.

## 검증된 것

- Hanzi Writer(v3.7.3, MIT, `hub/app/js/vendor/hanzi-writer.min.js`)에 **커스텀 한글 자모 데이터 주입 성공** — `charDataLoader` 옵션으로 한자 대신 자체 제작 stroke/median 데이터 로딩 가능함을 실제로 확인.
- 좌표계 검증: 실제 라이브러리가 렌더링에 적용하는 transform을 직접 읽어서(`translate(x,y) scale(s,-s)`) — **Y축이 위로 증가하는 좌표계**(그래픽 표준 SVG와 반대)임을 실측 확인, 문서에 명시 안 돼 있던 부분이라 실제 렌더링해서 알아냄.
- ㅣ·ㅇ·ㄱ 3개 자모를 이 좌표계에 맞춰 직접 제작 → 브라우저에서 렌더링해 각 도형의 bounding box가 예상 비율(ㅣ=가늘고 김, ㅇ=정사각형에 가까운 원, ㄱ=L자형)과 일치하는 것 확인.
- 애니메이션(획순 보여주기) 정상 동작.

## 확인 못 한 것 (다음에 필요)

- **퀴즈 모드(사용자가 직접 따라 그려서 채점받는 기능)를 자동화 테스트로는 검증 못 함** — 라이브러리가 실제 마우스/터치 이벤트를 리스닝하는 내부 타겟 엘리먼트를 찾아 합성 이벤트를 쐈지만 콜백이 안 잡힘(자동화 스크립트의 한계로 보임, 라이브러리 버그는 아닐 가능성 높음). **실제 사람이 마우스/터치로 직접 그려보는 수동 테스트가 필요.**
